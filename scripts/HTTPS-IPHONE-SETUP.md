# iPhone 安装自签证书步骤（包0）

> 前提：服务器上已以 root 执行 `bash /opt/learn-app-v3/scripts/https-selfsigned.sh`，
> 并重启服务 `systemctl restart learn-app-v3`（日志里看到 `HTTPS listening on :8443`）。
> 阿里云安全组需放行 8443 端口（8080 只是临时下载证书用，可随时关闭）。

## 步骤

1. **下载描述文件**
   iPhone 用 Safari（必须是 Safari，微信里打不开）访问：
   `http://8.162.12.71:8080/ca.mobileconfig`
   点"允许"下载描述文件。

2. **安装描述文件**
   设置 → 通用 → VPN 与设备管理 → 顶部"已下载的描述文件" → 点"LearnApp 证书" → 安装 → 输入锁屏密码 → 安装。

3. **信任证书**（关键一步，不做这步 Safari 还是不认）
   设置 → 通用 → 关于本机 → 证书信任设置 → 打开 "LearnApp Local CA" 的开关 → 继续。

4. **用 HTTPS 打开学习软件**
   Safari 访问 `https://8.162.12.71:8443`
   首次可能提示"此连接非私人连接"→ 点"显示详细信息" → "访问此网站"。
   以后都用这个 https 地址，录音按钮才能用。

5. **添加到主屏幕（可选，但建议）**
   Safari 分享按钮 → "添加到主屏幕"。从主屏幕图标打开是全屏 App 形态，录音同样可用。
   注意：主屏幕 App 和 Safari 是两套 Web 数据，首次打开 https 地址时的证书信任
   在两边都要确认一次（主屏幕 App 内点"显示详细信息→访问此网站"）。

## 验证录音

- 进英语 → 跟读题 → 点"🎤 录下我的朗读" → 允许麦克风 → 说话 → "⏹ 停止录音"
  → 点"▶ 回放我的录音"能听到自己的声音 = 成功。
- 如果点录音按钮提示"录音需要安全连接"，说明当前是 http 打开的，
  请确认地址栏是 `https://` 开头。

## 常见问题

- **8080 下载页打不开**：服务器上临时下载服务只开 10 分钟。重开：
  `cd /opt/learn-app-v3/tls && python3 -m http.server 8080`
- **证书过期**：自签证书有效期 825 天，到期后重新跑一遍脚本即可。
- **换了服务器 IP**：证书是按 IP 签的，IP 变了必须重新生成。
